# DSA City Map Project

Graph-based city-map route-finding final project with a console interface.

**Portfolio:** [Carl Renz Colico](https://github.com/renzkie8) · **Year:** Year 2

## Methodology

Represent city connections as a weighted graph; use Dijkstra’s algorithm for shortest paths and DFS for connectivity.
